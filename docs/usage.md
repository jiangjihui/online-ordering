# 使用指南

## 系统入口

| 端 | 地址 | 说明 |
|----|------|------|
| 首页 | `http://localhost:3000/` | 系统入口页面 |
| 顾客点餐 | `http://localhost:3000/order/{桌号}` | 扫码或直接访问 |
| 后厨看板 | `http://localhost:3000/kitchen` | 需登录（kitchen 账号） |
| 管理后台 | `http://localhost:3000/admin` | 需登录（admin 账号） |
| 登录页 | `http://localhost:3000/login` | 后厨/管理端登录 |

---

## 顾客端

### 扫码点餐

1. 顾客扫描餐桌上的二维码，自动跳转到对应桌号的点餐页面（如 `/order/1`）
2. 也可以直接在浏览器访问 `http://localhost:3000/order/{桌号}` 进入点餐

### 浏览菜品

- 顶部标签栏按分类筛选（热菜、凉菜、汤、主食、饮品）
- 支持搜索框输入菜名搜索
- 辣味菜品会显示辣椒标识

### 加入购物车

1. 点击菜品卡片上的 **+** 按钮添加到购物车
2. 页面左下角浮动按钮显示已选数量，点击展开购物车面板
3. 在购物车中可调整数量、删除菜品、添加备注
4. 套餐同样可加入购物车

### 下单

1. 确认购物车内容后，点击 **下单** 按钮
2. 下单成功后自动跳转到订单状态页面
3. 桌台状态自动变为"用餐中"

### 加菜

1. 在订单状态页面点击 **继续加菜**，回到点餐页面
2. 再次加入购物车并下单，新菜品会追加到当前订单

### 查看订单状态

- 订单状态页面实时显示每个菜品的制作状态：
  - **待做** → **制作中** → **已完成**
- 通过 WebSocket 实时更新，无需手动刷新

### 呼叫服务员

- 点击页面上的 **呼叫服务员** 按钮
- 呼叫信息会实时推送到后厨看板和管理后台

## 后厨端

### 登录

1. 访问 `http://localhost:3000/login`
2. 使用 `kitchen / kitchen123` 登录
3. 自动跳转到后厨看板

### 查看订单

- 看板分为 **待处理订单** 和 **已完成订单** 两个区域
- 新订单通过 WebSocket 实时推送，无需手动刷新
- 每张订单卡片显示：桌号、下单时间、菜品列表、备注

### 标记制作状态

每个菜品支持三种状态切换：

| 当前状态 | 操作 | 变为 |
|----------|------|------|
| 待做 | 点击「制作」 | 制作中 |
| 制作中 | 点击「完成」 | 已完成 |

- 标记单品为"制作中"时，订单自动进入"制作中"状态
- 所有菜品标记为"已完成"时，订单自动变为"已完成"

### 整单完成

- 点击订单卡片上的 **整单完成** 按钮，将所有未完成菜品一次性标记为已完成

### 处理服务员呼叫

- 页面顶部橙色区域显示待处理的呼叫
- 显示桌号和呼叫时间
- 点击 **处理** 按钮标记为已处理

## 管理后台

### 登录

1. 访问 `http://localhost:3000/login`
2. 使用 `admin / admin123` 登录
3. 自动跳转到管理后台仪表盘

### 仪表盘

- 就餐中桌台数
- 待处理订单数、制作中订单数
- 今日营收
- 在架菜品数
- 热门菜品 TOP5（按销量排序）
- 最近完成订单

### 菜品管理

| 操作 | 说明 |
|------|------|
| 新增菜品 | 填写名称、分类、价格、描述，上传图片 |
| 编辑菜品 | 修改菜品信息 |
| 售罄开关 | 一键标记菜品售罄，顾客端不再显示可点 |
| 上架/下架 | 控制菜品是否在顾客端展示 |
| 删除菜品 | 永久删除菜品 |

### 分类管理

- 新增、编辑、删除分类
- 设置分类排序顺序
- 支持中英文名称

### 套餐管理

- 创建套餐：设置名称、价格，选择包含的菜品及数量
- 编辑套餐：修改套餐内容和价格
- 上架/下架控制

### 餐桌管理

- 新增、编辑、删除餐桌
- 设置桌号、区域（大厅/包间/露天）、容量
- 查看餐桌状态（空闲/用餐中/预留）
- **生成二维码**：点击 QR 码图标，生成对应桌号的点餐二维码，可打印
- **清台**：将用餐中的餐桌恢复为空闲状态

### 订单管理

- 按条件筛选订单（桌号、状态、日期范围）
- 查看订单详情和菜品制作状态
- 导出营收数据

## WebSocket 实时事件

系统通过 WebSocket 实现前后端实时通信，所有状态变更自动推送：

| 事件 | 触发时机 | 推送对象 |
|------|----------|----------|
| `order.created` | 顾客下单 | 后厨、管理端 |
| `order.item-status-updated` | 菜品状态变更 | 后厨、管理端、对应桌顾客 |
| `order.completed` | 订单全部完成 | 后厨、管理端、对应桌顾客 |
| `waiter-call.created` | 顾客呼叫服务员 | 后厨、管理端 |
| `waiter-call.handled` | 呼叫被处理 | 后厨、管理端 |

频道说明：
- `/topic/admin` — 后厨和管理端订阅
- `/topic/table/{tableId}` — 顾客端按桌号订阅
